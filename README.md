## How I work

Stability is not a phase at the end. It is the order I do things in.

**Verification, fastest layer first**
1. **Unit tests** — the cheapest place to catch a regression, and the only layer fast
   enough to run on every commit
2. **UI automation** — Appium, Playwright, BDD with Gherkin. Gherkin keeps specs
   readable by QA and product, not just engineers. This is also where I put AI agents
   to work writing and maintaining the suite.
3. **Manual, on real devices** — BrowserStack, for what automation cannot see: OEM
   quirks, unusual screen sizes, bad connections

**Foundations**
- **Multi-module** — Android and Java libraries split so builds stay fast and teams
  stop blocking each other
- **Clean Architecture** — so the app outlives the team that wrote it
- **CI/CD** — every release ships through the pipeline, never from a laptop. Built
  this from nothing twice.

I spent a year managing 13 engineers at Gojek, then chose to go back to building. IC
is the work I am best at, not a rung I have not reached.
